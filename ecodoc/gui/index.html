        том соберётся с настоящими таблицами. Без выгрузок источники возьмутся из
        инвентаризации, а вместо результатов останется заглушка.

Выбор ИИ вручную (провайдер и модель)

      
По умолчанию — Cohere: ключ бесплатный, без карты
        (получить: dashboard.cohere.com/api-keys → вставьте в поле
        «API-ключ» ниже). Лимит бесплатного ключа — 20 запросов в минуту,
        программа сама выдерживает паузу. Локальный (Ollama) — приватно и без
        лимитов, но медленно; остаётся запасным. Запасной провайдер подхватит,
        если основной недоступен.
